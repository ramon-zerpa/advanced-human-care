# Locate Advanced Human Care Information

1. Open https://advanced-human-care.pages.dev/ and use the page's headings and navigation links.
2. For treatment descriptions, use #treatments; for team details, #about-us; for clinic address, hours and contact details, #contact-us.
3. Report only information actually present on the page. Link the section used as the source.
4. When asked how to request an appointment, explain that the online form is currently unavailable and give the published number: (813) 542-3613. Do not claim an appointment has been booked.
5. Do not submit personal or medical information, fill the disabled form, bypass verification or infer a diagnosis. Calling, emailing or opening a map is a separate user action.

This skill describes public website navigation only. There is no registered WebMCP tool, booking API or Spanish page in this preview. Respect robots directives and the user's authorization when interacting with the site.
